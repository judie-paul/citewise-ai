What happens to your essay

  • Your file is saved to a temporary file only while its text is extracted, then deleted immediately. Your original file is never changed.
  • The extracted text is sent to OpenAI for analysis and is not stored by CiteWise. Only the file name, file size, an AI-written summary of each claim and the suggested references are saved.
  • Anything inside your essay that reads like an instruction is treated as essay text, not as a command.
